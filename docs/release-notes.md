## TaiM 0.0.1-beta.2

- 新增分类管理、应用别名、日期范围查询和逐日使用记录。
- 新增 JSON 备份恢复与 CSV 导出，恢复前自动备份原数据库。
- 新增主题切换、窗口大小记忆、忽略应用和空闲阈值设置。
- 修复休眠负数时长、跨小时与跨天统计、退出缓存保存及图表资源释放。
- 新增 Windows 安装版更新检查、下载进度和重启安装。
- 新增应用内本地更新日志及远程新版本说明。

### 下载与安装

下载本 Release 的 `TaiM-Windows-0.0.1-beta.2-Setup.exe` 安装。Windows x64，数据保存在本机；此为未签名测试版，安装时可能出现系统信誉提示。

应用内“设置 → 关于”提供更新检查和更新日志。开发模式不下载和安装更新。首次公开发布尚无更早安装版，后续发布更高版本后可验证在线覆盖升级。

Release 同时提供更新描述文件、blockmap 和 SHA256SUMS.txt，自动更新所需文件请保留。
