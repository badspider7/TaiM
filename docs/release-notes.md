## TaiM 0.0.1-beta.3

- 新增 Chrome / Edge 前台网站计时，显示页面标题、具体网址及停留时间，支持按域名汇总和展开页面。
- 支持网站日期筛选、搜索、CSV 导出、JSON 备份恢复和清空记录。后台、无痕、空闲、锁屏及休眠不计时。
- 网站安装说明移到独立使用说明页，新增可公开分发的扩展 ZIP 和本机配对功能。
- 统一应用详情、分类、网站、主题设置和应用建议列表的下拉样式，适配浅色及深色主题、键盘导航和长列表滚动。
- 修复应用图标模糊，使用系统大尺寸图标并刷新旧缓存。
- 排除 TaiM 自身统计，清理历史误计的自身记录。

### 下载与安装

下载本 Release 的 `TaiM-Windows-0.0.1-beta.3-Setup.exe` 覆盖安装。Windows x64，数据保存在本机；此为未签名测试版，安装时可能出现系统信誉提示。

安装前从系统托盘退出旧版 TaiM。覆盖安装保留用户数据；仍建议先在“设置 → 数据”导出 JSON 备份。此版会按用户设置排除 TaiM 自身，并删除误计的自身记录，不删除其他应用历史。

### 网站扩展

可直接使用“网站 → 使用说明 / 扩展下载”中的内置扩展，免下载且自动配对。

也可下载本 Release 的 `TaiM-Browser-Extension.zip`，解压后在 Chrome / Edge 的扩展管理页开启开发者模式，加载已解压的扩展。再从 TaiM 使用说明页复制本机配对码，点击浏览器扩展图标粘贴保存。公开 ZIP 不包含个人密钥。

支持 Chrome / Edge 120+。每个浏览器配置文件需要单独加载和配对。已安装旧扩展的用户，请重新准备内置扩展目录或覆盖原扩展目录，再在扩展管理页点击“重新加载”。不要重复安装两份。

标题、网址查询参数可能含个人信息，导出的 JSON / CSV 请妥善保管。记录只保存在本机。具体步骤和计时边界见 [网站计时使用说明](https://github.com/badspider7/TaiM/blob/main/docs/browser-extension.md)。

应用内“设置 → 关于”提供更新检查和更新日志。开发模式不下载和安装更新。

Release 同时提供更新描述文件、blockmap 和 SHA256SUMS.txt，校验文件覆盖安装包、更新元数据与扩展 ZIP。自动更新所需文件请保留。
