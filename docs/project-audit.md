# TaiM 项目检查与完善记录

日期：2026-11-18

## 修复的问题

| 问题 | 修复方式 |
| --- | --- |
| 空闲休眠时直接写入负 300 秒，可能造成负数统计 | 空闲停止新会话；锁屏、休眠立即结束当前会话，不扣减历史数据 |
| 缓存仅按应用名称合并，跨小时、跨天数据归属错误 | 按应用和本地小时分桶，跨边界分段保存 |
| 多张表分别异步更新，保存失败后仍清空缓存 | 同步 SQLite 事务更新总时长、小时、日记录；失败保留缓存重试 |
| 托盘退出直接终止进程，可能丢失缓存 | 统一正常退出路径，退出前结束会话并落盘 |
| 刷新页面重复初始化计时器和电源监听 | 移至应用生命周期，一次注册；异步采样防重入、停止后丢弃迟到结果 |
| 每秒提取并写入图标；安装目录可能无写权限 | 使用 Electron 文件图标 API，缓存 data URL，限制缓存数量 |
| 预加载脚本以 CJS 编译却使用 mjs 后缀 | 明确输出 cjs，启用沙箱与上下文隔离，IPC 通道白名单 |
| 应用详情把 Promise 当数组调用 reduce，且使用过期的应用列表 | 异步刷新应用资料后合并，所有调用处等待结果 |
| 数据库清空重复调用 run、日记录删除列名错误、应用更新遗漏 id 参数 | 修复 SQL 和参数绑定，并让类型检查覆盖主进程 |
| 数据库全局版本相同即跳过初始化，新表可能缺失 | 每次启动幂等检查所有表并添加查询索引 |
| 卡片首次值不更新、对比应用数使用错误 id、小时取整导致除零 | 改为计算属性，按 appModelId 去重，使用原始秒数计算变化 |
| 日期依赖系统区域格式；月末切换月份可能溢出；一月不显示去年十二月对比 | 使用固定本地日期格式，以年月构造日期并正确处理跨年 |
| 窗口按钮不断注册监听、图表离开页面未销毁 | 固定监听函数并在卸载时解绑、释放图表 |
| 分类与详情入口被注释，侧栏状态可能错误 | 恢复入口，按当前路由计算选中项 |
| 设置开关只有界面状态，检查更新仅模拟等待 | 设置落盘并应用系统功能；关于页读取实际版本并打开发布页面 |
| SQLite 路径绑定开发者旧机器目录，重建脚本混用模块格式 | 运行时从应用路径解析，重建脚本统一 ESM 并复制匹配 Electron 的绑定 |

## 已补齐的功能

- 设置持久化：浅色、深色、跟随系统，记住窗口大小。
- Windows 安装版开机启动，启动后隐藏到托盘；开发环境禁用该开关。
- 空闲阈值 1–60 分钟，应用名称或程序完整路径忽略规则，不区分大小写。
- 分类创建、重命名、删除及应用归类；分类展示累计时长。
- 详情页日期范围、名称和别名搜索、分类筛选、应用逐日历史及别名编辑。
- JSON 导出恢复、CSV 导出。恢复前校验版本、ID、引用、日期、时长和重复记录；确认后自动备份原库，再在事务中替换并重算日表与总时长。
- 概览定时和聚焦刷新，图表模块按需引入；尊重减少动态效果的系统偏好。

## 验证

自动回归使用独立临时目录，不读取或覆盖用户统计数据库。覆盖 Windows 原生采样模块加载、建表幂等、跨午夜分桶、负数拒绝、事务回滚、缓存重试、设置持久化、空闲/忽略/停止竞态、实际生产渲染器启动、分类增删改、四种统计视图、备份导入取消与确认、导出及非法数据校验。另检查生产构建和 ESLint。

测试目录会输出结果 JSON 和页面截图供排查，路径由 `pnpm test` 打印。

## 尚未完成及后续建议

1. **网站使用时间**：当前按 Windows 前台程序计时。浏览器内部标签页网址需要浏览器扩展或额外集成，不能仅凭窗口标题准确区分。建议先明确支持哪些浏览器及是否保存域名或完整 URL。
2. **完整多语言**：移除了无法实际切换界面的英文选项。目前统一简体中文；后续需集中提取文案并适配日期和时长格式。
3. **统计图按分类堆叠、目标和提醒**：目前分类管理与详情筛选可用，原有图表仍展示全部应用合计。
4. **安装包回归**：源码环境已验证；安装、卸载、开机启动注册、不同分辨率与多屏、长时间锁屏/休眠应在安装版另测。
5. **长期性能与依赖维护**：图标、事件和图表生命周期已改善，尚未完成长时间内存曲线测量或框架依赖大版本升级。
6. **历史数据修复**：旧版本已写错的负数、跨日归属和累计误差无法可靠自动重建。保留原数据库，按需另做有预览与备份的数据修复工具。新 JSON 恢复会拒绝负时长及重复小时桶等无效数据。
7. **异常退出**：正常退出即时落盘，定时保存周期为 15 秒；崩溃、强杀和断电仍有未保存窗口。需要更严格持久性时可增加日志恢复机制。

本轮没有执行发布、上传或修改项目外的开机启动项。
