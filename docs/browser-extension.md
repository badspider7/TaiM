# 网站计时扩展：下载与使用说明

支持 Windows 上的 Chrome / Edge 120+，需要 TaiM 保持运行。

## 下载

- [前往 TaiM Releases 下载扩展](https://github.com/badspider7/TaiM/releases)：选择与桌面应用同一版本的附件 **TaiM-Browser-Extension.zip**，解压到固定目录。此通用包不包含个人配对码。
- 若当前 Release 尚无 ZIP，可用 TaiM 的“网站 → 使用说明 / 扩展下载 → 准备 / 打开内置扩展目录”，无需联网下载，已为本机自动配对。
- 从源码打包：执行 `pnpm package:extension`，文件生成到 `release/当前版本/TaiM-Browser-Extension.zip`。`pnpm release:win` 和发布流水线也会生成此文件；发布前的本地构建不代表 GitHub 附件已上线。

## 安装与配对

1. 在 TaiM → 网站，开启计时，进入“使用说明 / 扩展下载”。
2. 获取上面的内置扩展目录，或下载并解压通用 ZIP。
3. Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
4. 开启“开发者模式”，点击“加载已解压的扩展”，选择包含 `manifest.json` 的目录。
5. 内置扩展自动配对。通用包需要在 TaiM 使用说明页点击“复制本机配对码”，再点击浏览器工具栏里的 TaiM 扩展图标，粘贴并保存。
6. 返回 TaiM 网站页，确认“扩展已连接”，前台浏览普通网页十几秒，再点击“查询 / 刷新”。

每个浏览器、每个配置文件需要分别加载和配对。不要在同一个配置文件中重复安装内置版和通用版。更新时保留原扩展目录，在扩展管理页点击“重新加载”。下载解压后的目录不要随意移动或删除。

## 查看记录

- 默认按具体网址展示：页面标题为主、网址为辅。无标题时显示“未命名页面”。
- 标题取所选日期范围内最近的非空小时标题；同一 URL 在同一小时内只保留最后记录的标题，不是每次访问的标题历史。
- 按域名汇总显示主要页面（停留时间最长的 URL）及页面数量，点击数量可展开该域名的具体页面。
- 可按日期、网址或标题搜索，导出网站 CSV。JSON 备份包含网站记录。

## 计时边界

只统计系统前台浏览器的当前标签页。后台标签页、无痕窗口、浏览器内部页面不计时；空闲、锁屏和休眠暂停。约每秒采样，切换页面有约 1 秒误差；断连或系统前台观测失效后最多 2.5 秒停止，不回填未观测的浏览历史。网页时长属于浏览器使用时长的细分，不重复加进应用总计。

网页标题由网站决定，可能为空、动态变化或不能准确描述内容。缺失的旧标题无法凭空恢复，需要重新访问后采集。仅有 `#` 片段变化的路由会合并为同一网址；目前不做每次访问或每个动态标题的会话级统计。

## 隐私和连接

标题可能含聊天对象、搜索词或文档名；URL 查询参数可能含敏感信息。记录和配对码保存在本机，不上传，但 JSON / CSV 备份包含标题和网址，请按个人数据保管。URL 中的账号密码和 `#` 片段会移除。

通用 ZIP 不含密钥，可以公开分发。内置自动配对后的扩展目录和复制的配对码属于本机凭据，请勿分享。手动配对码保存在扩展的 `storage.local`，不通过浏览器同步。

连接服务只监听 `127.0.0.1:17384`，校验扩展来源与随机配对码。连接失败时检查 TaiM 是否运行、计时是否开启、配对是否正确、端口是否被占用；换电脑需重新配对。关闭网站计时即停止连接服务，应用统计照常运行。
