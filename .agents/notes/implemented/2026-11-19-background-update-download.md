# Windows 更新在后台下载，由用户确认安装

Status: implemented

## 问题

此前需要用户先决定何时下载，再决定何时安装。下载可以在使用 TaiM 的同时完成，安装则需要保存当前统计并重启应用。

## 决定

启动和手动检查共用 `UpdateService.check()`。查到新版后由服务启动下载，下载完成后才提示重启安装。沿用已有启动检查开关。用户确认安装后仍走保存统计数据的流程，普通退出保持自动安装关闭。

## 考虑过的替代方案

- 保留手动下载。用户能决定何时使用网络，但要多操作一次才能进入下载流程。
- 由 electron-updater 在检查时直接启动下载。使用库默认行为可以少写一个调用，但 TaiM 还需要为下载阶段单独设置进度状态、错误归属和重试入口。由服务发起下载可以复用这些状态转换。

## 影响与代价

启用启动检查时会自动使用网络下载更新。关闭启动检查后，可从关于页手动检查并下载。更新包校验和缓存由 electron-updater 处理。安装需要用户确认，保存统计失败时可重试安装。

## 涉及文件

- [UpdateService.ts](../../../electron/update/UpdateService.ts) 检查到目标版本后进入下载状态，处理下载进度、阶段错误与重试。下载完成后才接受安装请求。关闭库的全量更新日志与退出时安装，数组格式的远程说明按目标版本提取。
- [UpdateNotice.vue](../../../src/components/UpdateNotice.vue) 在全局提示内提供「重启并安装」和「稍后」。安装失败时显示错误和重试入口。
- [About.vue](../../../src/pages/setting/components/About.vue) 展示进度、重试和安装入口。日志区域一次展示一个版本，有远程目标时显示该版本说明，其余时间显示安装包附带的最新条目。历史条目保留在现有日志源和发布页面。
- [README.md](../../../README.md) 和 [更新说明](../../../docs/updates.md) 同步应用行为与发布验证范围。回归证据见 [updates.mjs](../../../tests/updates.mjs) 和 [integration.mjs](../../../tests/integration.mjs)。

## 验证与限制

- 本轮的 `pnpm lint`、`pnpm build` 和 `pnpm test` 已通过。测试覆盖自动下载、并发请求去重、失败重试、保存统计失败时阻止安装、延后安装、离线日志和远程说明文本渲染。
- 下载和校验使用真实 electron-updater 与本机 HTTP 夹具验证。真实 GitHub 发布源和 NSIS 覆盖安装仍未实测。
