# 应用分类支持批量选择与拖放

Status: implemented

## 问题

分类页原先只能逐个打开应用下拉框，应用数量多时重复操作慢，也不便把当前搜索结果一起归类。

## 决定

应用列表支持复选框和点击名称选择，支持一键选择当前搜索结果。选中后可在批量工具栏指定分类，或点击左侧分类的「归入」按钮。应用行可拖到左侧分类；拖动已选中的应用时移动整个选择集，拖动未选中的应用时只移动该应用。原有逐行下拉框继续可用。

批量接口在一个 SQLite 事务中只更新 `AppModels.categoryId`，验证分类及所有应用 ID，任何一个无效则全部回滚。别名、使用时长、历史记录和备份格式不变。拖放与按钮共用同一接口，按钮和复选框也提供不依赖拖放的操作路径。

## 考虑过的替代方案

- 只增加拖放：触屏和键盘用户仍需逐个操作，也难以一次选多个应用。
- 在渲染端逐次调用旧接口：中途失败会留下部分应用已改、部分未改的状态。
- 取消逐行下拉框：单个应用的快速修改反而增加步骤。

## 影响与代价

分类页新增选择状态、批量工具栏及拖放高亮。选择会跨搜索词保留，操作完成后清除已归类的选择；删除应用或重新读取列表时移除失效 ID。批量事务一次最多接收 10000 个不同应用 ID。

`pnpm lint`、`pnpm build` 和 `pnpm test` 已通过；Electron 集成测试覆盖两个应用一起归类、无效 ID 回滚及单个应用拖放，并核对分类页截图。浏览器原生拖放不适用于触屏，复选框和按钮可完成同样操作。
